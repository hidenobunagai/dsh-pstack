# pstack

`pstack` is the short invocation name for the **poteto-mode** skill. The two names are the same mode; the short name exists only because poteto-mode is hard to type (adopted 2026-11-02).

Read the poteto-mode skill in full and follow it as if it had been invoked directly. It is bundled at `../poteto-mode/SKILL.md` relative to this file.

Documents, playbooks, and other skills may still call the mode poteto-mode. Treat every such reference as meaning this mode, and treat instructions in the poteto-mode skill as applying in full when this skill is invoked.
